Rubric & Mode Rules

🫧 Mode A: Bubbles (Letter Recognition)

  • 5+ Simultaneous Bubbles: At least 5 bubbles float upward with randomized organic sway.
  • Popping & Scoring: Pressing a key matching a visible bubble removes it and awards +10 points (multiplied by combo streak).
  • Incorrect Key Penalty: Pressing a key with no matching bubble incurs an immediate -5 points penalty and resets combo.
  • Boundary Miss Ceiling: When a bubble reaches the top red laser line, a miss is recorded. Game ends when 6 misses are reached.
  • Dynamic Difficulty: Speed scales up automatically as your score increases.

🧲 Mode B: KeyMagnet (Keyboard Precision)

  • Target Key Station: Generates target keys from a configured array with a reflex countdown bar.
  • Home-Row Practice Set: Mandatory default practice set (A, S, D, F, J, K, L) plus selectable Top Row, Bottom Row, and Full sets.
  • Interactive Keyboard: Tactile feedback with mechanical keycap travel, bumps on F/J, and finger posture guidance.
  • Reaction Time: Accurate millisecond response tracking with speed tiers (⚡ Lightning, ★ Swift, Good).

⚙️ Global Controls & Technical Architecture

  • Controls: Start, Restart, and Reset operate smoothly without reloading the page.
  • Difficulty Modes: Easy, Medium, and Hard change velocities, timer windows, and quotas.
  • Technology: Pure semantic HTML5, modern responsive CSS3, and ES6+ JavaScript. Procedural audio synthesized via Web Audio API.
