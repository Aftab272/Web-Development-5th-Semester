Lecture 1

Introduction to Web Technologies

An overview of the Internet, the Web, and the tools behind websites.

Summary

This lecture introduces the Internet and the World Wide Web. It explains how browsers request pages from web servers and introduces HTML, CSS, and JavaScript as the core technologies used to build websites.

Topics Covered

  • Internet and World Wide Web
  • Web browsers and web servers
  • The client-server model
  • HTML for structure, CSS for presentation, and JavaScript for interaction
