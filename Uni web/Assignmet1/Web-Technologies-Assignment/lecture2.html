Lecture 2

HTML Basics

Build the structure and meaning of a web page.

Summary

HTML (HyperText Markup Language) organizes webpage content using elements and tags. A well-formed HTML document has a doctype, a head for page information, and a body for visible content.

Topics Covered

  • HTML elements, tags, and attributes
  • Document structure: doctype, head, and body
  • Headings, paragraphs, and lists
  • Links and semantic elements such as header, main, and footer

Example Code

<h1>My First Page</h1>
<p>HTML gives this page its structure.</p>
<a href="index.html">Go to home</a>

Output

My First Page

HTML gives this page its structure.

Go to home
