Lecture 3

HTML Forms and Media

Collect information and add rich media to a page.

Summary

HTML forms let visitors enter information and submit it. Form controls include text fields, email fields, and buttons. Images, audio, and video can also be included to make page content more useful and engaging.

Topics Covered

  • Form, label, input, and button elements
  • Input types such as text, email, and password
  • Labels and required-field validation
  • Adding images with descriptive alternative text

Example Code

<form>
  <label for="email">Email address</label>
  <input id="email" type="email" required>
  <button type="submit">Join</button>
</form>
<img src="photo.jpg" alt="A view of the campus">

Output

A labelled email field and Join button appear, followed by an image with alternative text for visitors using assistive technology.
