Lecture 4

Introduction to CSS

Style HTML content with Cascading Style Sheets.

Summary

CSS controls how HTML elements look on screen. A CSS rule contains a selector and declarations made from property-value pairs. Styles can be placed in an external stylesheet, which keeps a website consistent across pages.

Topics Covered

  • CSS rules, selectors, properties, and values
  • External, internal, and inline styles
  • Text, color, background, and border styling
  • Linking an external stylesheet to HTML

Example Code

h1 {
  color: #2f5fa8;
  text-align: center;
}

<link rel="stylesheet" href="style.css">

Output

A centered blue heading

The linked stylesheet applies its rules to the page.
