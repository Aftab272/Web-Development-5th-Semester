Lecture 5

CSS Selectors

Choose exactly which elements receive a style.

Summary

A CSS selector matches one or more HTML elements. Type selectors target element names, class selectors can be reused, and ID selectors target a unique element. Combining selectors helps organize page styles precisely.

Topics Covered

  • Element selectors, such as p and h1
  • Class selectors, written with a dot
  • ID selectors, written with a hash
  • Grouping and descendant selectors

Example Code

p {
  color: #526174;
}

.highlight {
  background-color: #edf3fc;
}

#page-title {
  color: #2f5fa8;
}

Output

Page title

All paragraphs use muted text.

An element with the highlight class has a pale blue background.
