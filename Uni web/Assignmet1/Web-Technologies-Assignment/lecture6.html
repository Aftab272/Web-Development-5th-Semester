Lecture 6

CSS Box Model & Layout

Understand element spacing and arrange page content.

Summary

Every element is displayed as a box made up of content, padding, border, and margin. CSS layout tools such as Flexbox help position and align these boxes. The box-sizing property makes sizing easier to manage.

Topics Covered

  • Content, padding, border, and margin
  • Width, height, and box-sizing
  • Spacing with margin and padding
  • Basic Flexbox layout and alignment

Example Code

.card {
  box-sizing: border-box;
  padding: 16px;
  border: 1px solid #d8e0eb;
  margin: 12px;
}

.row {
  display: flex;
  gap: 12px;
}

Output

A card has space inside its border, space outside it, and a light outline. Items in a flex row sit beside each other with a consistent gap.
