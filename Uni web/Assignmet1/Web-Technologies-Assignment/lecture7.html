Lecture 7

Responsive Web Design

Make pages comfortable to use on phones, tablets, and desktops.

Summary

Responsive design adapts a page to different screen sizes. Flexible widths, viewport settings, and CSS media queries let a layout change naturally between small and large screens. A mobile-first approach starts with the smallest layout.

Topics Covered

  • Viewport meta tag
  • Fluid and flexible layouts
  • Media queries and breakpoints
  • Readable text and usable controls on mobile screens

Example Code

.container {
  width: min(900px, 100% - 32px);
  margin: 0 auto;
}

@media (max-width: 560px) {
  .columns {
    display: block;
  }
}

Output

The content stays centered and constrained on a wide screen. On a narrow screen, the columns stack so they remain easy to read.
