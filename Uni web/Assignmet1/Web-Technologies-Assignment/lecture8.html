Lecture 8

Introduction to JavaScript

Add behavior and interactivity to web pages.

Summary

JavaScript is a programming language that runs in the browser and can respond to user actions. It can select HTML elements, update their content, and react to events such as a button click.

Topics Covered

  • Including JavaScript in a webpage
  • Variables and simple values
  • DOM elements and changing page content
  • Events and event listeners

Example Code

<button id="hello-button">Say hello</button>
<p id="message"></p>

<script>
  document.querySelector("#hello-button")
    .addEventListener("click", function () {
      document.querySelector("#message").textContent = "Hello!";
    });
</script>

Output

When the visitor clicks “Say hello”, JavaScript displays “Hello!” in the paragraph.
